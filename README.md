# OneTake

**OneTake** — это десктопное приложение для записи экрана, звука с микрофона и видео с веб-камеры. Идеально подходит для создания обучающих роликов, демо, презентаций и баг-репортов.

## Возможности

*   **Запись экрана**: Весь экран, окно приложения или выделенная область.
*   **Веб-камера**: Режим "картинка в картинке" с возможностью перемещения окна камеры во время записи.
*   **Аудио**: Запись системных звуков и микрофона с визуализацией уровня.
*   **Производительность**: Оптимизировано для Windows 10/11, поддержка аппаратного ускорения (где доступно).
*   **Простота**: Интуитивный интерфейс, быстрый старт записи.

## Установка и запуск

Подробные инструкции по настройке окружения разработчика находятся в файле [docs/setup.md](docs/setup.md).

Кратко:
1.  Установите Python 3.10+.
2.  Установите зависимости: `pip install -r requirements.txt`.
3.  Запустите приложение: `python src/main.py`.

## Структура проекта

*   `src/`: Исходный код приложения.
    *   `src/main.py`: Точка входа.
    *   `src/ui/`: Графический интерфейс (PySide6).
    *   `src/core/`: Логика записи и работа с устройствами.
    *   `src/utils/`: Утилиты и конфигурация.
*   `docs/`: Документация.
*   `tests/`: Тесты.
