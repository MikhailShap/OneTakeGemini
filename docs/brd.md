# Бизнес-ТЗ: OneTake — запись экрана + микрофона + веб-камеры

## 1) Общая информация

### 1.1 Назначение продукта
OneTake — десктоп-приложение для записи обучающих роликов, демо, созвонов, презентаций, игр и инструкций. Приложение записывает:
*   видео экрана,
*   звук с микрофона,
*   видео с веб-камеры в виде окошка поверх экрана (picture-in-picture) в итоговом файле,
*   с возможностью перемещать окошко веб-камеры во время записи, чтобы это отображалось в финальном видео.

### 1.2 Целевая аудитория
*   авторы обучающих роликов, преподаватели
*   менеджеры/аналитики (демо, презентации)
*   разработчики/QA (репорты, баг-репорты)
*   стримеры/контент-креаторы (запись экрана + facecam)
*   обычные пользователи (быстро записать инструкцию)

### 1.3 Целевая платформа (на первом этапе)
Windows 10/11

## 2) Ключевые принципы продукта
*   **“Настроил за 30 секунд”** — главный сценарий должен быть быстрым и понятным.
*   **WYSIWYG**: предпросмотр до записи и во время записи должен максимально соответствовать тому, что получится в финальном видео.
*   **Не мешать записи**: интерфейс аккуратный, компактный, не перекрывает важное, по возможности не попадает в запись.
*   **Надёжность важнее “фич”**: лучше меньше функций, но стабильная запись, корректный звук и синхронизация.

## 3) Основные пользовательские сценарии

### 3.1 “Быстрая запись”
1.  Открыть OneTake
2.  Выбрать экран (или монитор)
3.  Выбрать микрофон
4.  Выбрать камеру (по умолчанию в правом нижнем углу)
5.  Нажать REC
6.  Остановить → предпросмотр → экспорт

### 3.2 “Запись с динамической камерой”
1.  Начать запись
2.  Во время записи перетащить окно камеры в другой угол
3.  Итоговый файл должен отразить перемещение окна (это распространённое ожидание в таких приложениях).

### 3.3 “Перезапись”
1.  Записал тестовый дубль
2.  Не понравилось → Перезаписать
3.  Вернуться к экрану подготовки (с сохранёнными настройками)

## 4) Функциональные требования

### 4.1 Экран “Домой / Библиотека”
Цель: быстро начать запись и управлять последними роликами.
Функции:
*   Кнопка Новая запись
*   Список последних записей (карточки): дата/время, длительность, разрешение, размер. Действия: Открыть предпросмотр / Экспорт / Открыть папку / Удалить
*   Поиск по записям (по имени/дате)
*   Настройки приложения

### 4.2 Экран “Подготовка к записи”
Цель: выбрать источники и настройки, увидеть итоговую композицию до старта.

#### 4.2.1 Настройки “Экран”
*   Режимы: Запись всего экрана/монитора, Запись окна приложения, Запись области.
*   Параметры: Частота кадров (24/30/60).
*   Курсор: показывать/скрывать, (опционально) визуализация кликов.
*   Удобные фичи: “Проверка захвата”, Профили.

#### 4.2.2 Настройки “Микрофон”
*   Параметры: Выбор устройства, Усиление.
*   Индикатор уровня (VU-meter).
*   Удобные фичи: Быстрая кнопка Mute, (опционально) “Улучшение голоса”.

#### 4.2.3 Настройки “Камера”
*   Параметры: Выбор камеры, Качество (авто/720p/1080p), Отзеркаливание.
*   Оформление: Размер, Скругление, Рамка, Тень, Позиция.

#### 4.2.4 “Сцена / Композиция” (экран + камера)
*   Предпросмотр композиции в реальном времени.
*   Настройка “Безопасные отступы”.
*   Кнопка “Сбросить композицию”.

#### 4.2.5 Дополнительные настройки перед записью
*   Таймер перед стартом (0/3/5/10 сек).
*   Горячие клавиши.
*   Куда сохранять.
*   Опция “Скрывать интерфейс”.

### 4.3 Процесс записи
#### 4.3.1 Управление записью
*   Компактный контроллер: REC/Таймер, Пауза/Стоп, Индикатор микрофона, (опционально) Метка/Скриншот.

#### 4.3.2 Окно веб-камеры во время записи
*   Можно перетаскивать во время записи (отражается в видео).
*   Прилипание к углам.

### 4.4 Экран “Предпросмотр”
*   Видеоплеер (play/pause, seek, volume).
*   Кнопка Перезаписать.
*   Простая обрезка (trim).
*   Отображение маркеров.

### 4.5 Экспорт
*   Форматы: MP4 (основной), WebM, (опционально) MKV.
*   Разрешения: Исходное, 2160p...480p.
*   Пресеты качества: Высокое, Сбалансированное, Компактное.
*   Доп. опции: Открыть файл/папку, Экспорт кадра.

### 4.6 Управление записями и данными
*   Автосохранение метаданных.
*   Корзина.
*   Очистка временных файлов.

## 5) Нефункциональные требования (качество)
*   **Производительность**: Отзывчивый UI, умеренное потребление ресурсов.
*   **Надёжность**: Обработка отключения устройств, нехватки места на диске.
*   **Синхронизация**: Отсутствие рассинхрона аудио/видео.
*   **Безопасность**: Приватность при захвате экрана.

## 6) Требования к дизайну и UI
*   Современный минимализм, тёмная тема.
*   Акцентный цвет: приглушённый фиолетовый.
*   Плавные анимации и микро-взаимодействия.
*   Понятные подсказки.

## 7) Требования к текстам/локализации
*   Язык интерфейса: RU (опционально EN).

## 8) Критерии приёмки
1.  Запись 10 сек (экран+мик+камера) воспроизводится корректно.
2.  Перемещение камеры во время записи видно в файле.
3.  Предпросмотр работает, экспорт в MP4 успешен.
