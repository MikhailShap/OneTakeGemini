# Инструкции для агентов (Agent Instructions)

Этот файл содержит контекст и правила для AI-агентов, работающих над проектом OneTake.

## Контекст проекта
OneTake — десктопное приложение на Python (PySide6) для записи экрана с веб-камерой.

## Правила кодирования
1.  **UI**: Используем PySide6. Все длительные операции (запись, конвертация) выносить в отдельные потоки (`QThread`), чтобы не блокировать GUI.
2.  **Стили**: Стараемся использовать QSS (Qt Style Sheets) или палитру Qt для темизации. Ориентируемся на темную тему ("современный минимализм").
3.  **Ошибки**: Логируем ошибки через модуль `logging`.
4.  **Типизация**: Используем Type Hints везде, где это возможно.
5.  **Докстринги**: Google-style docstrings для классов и методов.

## Ключевые архитектурные решения
*   **Захват**: Для MVP используем подход "Камера как окно поверх экрана". Это значит, что мы просто отрисовываем камеру в `QWidget` с флагом `WindowStaysOnTopHint`, а запись ведем всего экрана через FFmpeg. Это избавляет от сложного композитинга видеопотоков на лету.
